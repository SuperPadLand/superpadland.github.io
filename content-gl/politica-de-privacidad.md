**SuperPadLand** é un sitio web estático que **non recompila datos persoais** dos seus visitantes: non hai rexistro de usuarios, nin formularios que almacenen información, nin perfís publicitarios.

O sitio alóxase nun provedor de páxinas estáticas (por exemplo, GitHub Pages). Como calquera servidor web, o aloxamento pode rexistrar datos técnicos básicos de acceso (como o enderezo IP) con fins de seguridade e estatística, conforme a política de privacidade do devandito provedor.

Se no futuro se engaden servizos de terceiros (analítica, comentarios, etc.), esta política actualizarase para reflectilo.
